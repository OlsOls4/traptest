TrapTest — provider leaderboard

Intent: ONCHAIN_TX_LOOKUP · Ranking: pass rate, then traps run, then lower total testnet cost, then provider id — the same rules as traptest/leaderboard.py. A provider with zero scored traps is unranked, never shown as passing. Scoring is strict: a status mismatch fails the trap outright, and a missing provider field is a failure, never a pass (traptest/scoring.py).

Judge in 60 seconds (live build, from 1 Nov — disabled in mock mode)
  1. Enter one trap transaction hash below.
  2. TrapTest buys competing providers' answers on testnet (Direct Ask, one miner at a time).
  3. Each answer is scored pass/fail against the trap's known ground truth, with its receipt.
  4. The leaderboard below re-ranks. A stale or wrong answer is shown FAIL on screen — that is the built-in failure case, not a hidden error.

This input does nothing in mock mode by design. In the live build it triggers real testnet purchases only after the free-testnet gate has passed (see docs/how-to-run.md).
